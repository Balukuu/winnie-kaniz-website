# Kaniz Furnished Apartments - Website

A premium, production-ready website for Kaniz Furnished Apartments in Bugolobi, Kampala, Uganda. Designed for high conversion and a luxury guest experience.

## Features
- **Premium Aesthetic**: Inspired by high-end hospitality brands, featuring full-bleed cinematic photography and elegant typography.
- **Optimized Performance**: 
    - All images converted to **WebP** format for fast loading.
    - Videos compressed to **MP4 (H.264)** for seamless autoplay background use.
    - Lazy loading implemented for off-screen assets.
- **Mobile-First Design**: Fully responsive across all devices (Mobile, Tablet, Desktop).
- **Interactive Elements**:
    - Sticky navigation with backdrop blur.
    - Scroll-triggered animations (AOS.js).
    - Modern image sliders (Swiper.js) and lightboxes (GLightbox).
    - Floating WhatsApp button with pulse animation.
- **Airbnb Integration**: Direct booking links for all four apartments.

## Technology Stack
- HTML5, CSS3 (Vanilla)
- JavaScript (Vanilla)
- [AOS.js](https://michalsnik.github.io/aos/) (Animations)
- [Swiper.js](https://swiperjs.com/) (Sliders)
- [GLightbox](https://biati-digital.github.io/glightbox/) (Gallery)
- [FontAwesome](https://fontawesome.com/) (Icons)

## Folder Structure
- `/index.html`: Homepage with 12 sections.
- `/apartments/`: Individual residence detail pages.
- `/assets/images/`: Optimized WebP images and logo.
- `/assets/videos/`: Compressed MP4 tour videos.
- `/css/`: Custom stylesheets.
- `/js/`: Main interaction logic.

## Deployment Instructions
1. Upload the entire `winnie-kaniz-website` folder to your web server or hosting provider (e.g., Netlify, Vercel, or traditional cPanel).
2. Ensure the file paths remain intact.
3. The site is static and requires no backend database or special server-side configuration.
